# ✈️ FAPM-Display PC Server (飞行外设服务端)

FAPM-Display 是一款专为微软模拟飞行 (MSFS 2020 / 2024) 设计的商业级外设驱动服务端。它作为游戏底层与 ESP32 硬件之间的桥梁，负责抓取核心飞行遥测数据、融合真实的航空气象与通告，并通过局域网无线推流给外部硬件显示器（EFB）。

## ✨ 核心特性

- 🛫 **全自动环境构建 (静默注入)**：智能识别系统中的 MSFS (Steam / 商店版 / 2020 / 2024) 社区文件夹路径。若是首次运行，自动将通信所需的 `fsuipc-lvar-module` (WASM) 模块注入游戏，实现对小白用户零门槛的绿色免安装体验。
- 📡 **无感局域网寻址 (UDP)**：后台通过 `UDP 8766` 端口持续广播特征码，ESP32 硬件端上电连入 WiFi 后即可自动捕获 PC 端的 IP 地址并建立连接，真正的即插即用。
- ☁️ **多源航空数据融合**：
  - **SimBrief**: 自动提取最新生成的航线信息（起点、终点、备降场）与航行通告 (NOTAM)。
  - **NOAA**: 绕过第三方延迟，直接向美国国家气象局官方 API 索取最新的 TAF 机场预报。
  - **VATSIM**: 获取最高优先级的实时 METAR 实况气象，确保硬件显示风向与联飞环境 **100% 绝对一致**，并监控当前连线状态。
- 💬 **智能气象翻译引擎**：内置基于正则表达式的航空气象引擎，将枯燥的 METAR/TAF 原始报文解析并排版为易读的纯中文自然语言。
- ⚙️ **硬件级客制化控制**：提供现代化的扁平风格 UI 界面，用户可实时拖动滑块，通过 WebSocket 毫秒级下发屏幕背光、警告灯亮度与蜂鸣器音量的硬件 PWM 控制指令。

## 📂 商业发布包结构

当你将本程序打包发给其他飞友时，**最终的免安装发布文件夹**应包含以下结构：

```text
FAPM-Display-Driver/
 ┣ 🗂️ fsuipc-lvar-module/   (必须附带，用于服务端自检和自动注入社区)
 ┣ 📄 FapmDriver.exe        (C# 编译的单文件主程序)
 ┣ ⚙️ FSUIPC_WAPID.dll      (读取 WASM 底层内存的 C++ 动态库)
 ┗ ⚙️ SimConnect.dll        (微软官方的 C++ 原生通信库)
